chase

The chase is the rectangular iron frame that holds the composed type. Lines of type and the blank spacing material around them are packed inside it and locked tight, so that the whole page can be moved, inked and printed as one piece.

compositor

The compositor is the person who sets the type. Working letter by letter in a composing stick, the compositor decides the line length, the spacing between words and where each line breaks, and turns a manuscript into a page that reads well.

em

The em is a unit of measure that takes its size from the type. One em equals the point size of the typeface being set, so in 12 point type an em is 12 points, and in 40 point type it is 40.

About

chase is a small set of tools for working out page layouts. The calculator takes a page size, margins, columns and a type size, and works out column widths, gutters and line lengths following Bringhurst's principles. It draws the result as a page.

A second tool builds InDesign GREP patterns for paragraph styles, to find words, digits, punctuation or enclosed text.

Features

The calculator works in ems or millimetres, for single pages or facing pages with inner and outer margins, and sets column widths, gutters and baseline grid from the type size and leading. The preview shows margins, columns, baseline grid, text, the ragged edge and, when justified, rivers.

Text can be typed or pasted into an editor, or imported from Word, OpenDocument or HTML files. Simple marks give three heading levels, block quotes, source lines, italics and soft returns, and each style takes a size ratio set in the panel. Hyphenation and justification can be switched on.

The result exports as an InDesign file (IDML) with the page, margins, columns, baseline grid and text, and a final page that lists every setting and where to change it in InDesign.

The names

The calculator is called Compositor, Chase, Em, after letterpress. A compositor arranged type and spacing into lines and pages. A chase is the metal frame that held the composed page. An em is a unit equal to the type size, so spacing set in ems scales with the type.

Intro

A typographic layout calculator for designing multi-column page layouts. Set page dimensions, margins, columns, and typography settings to visualize and calculate optimal column widths, text box spans, and line lengths based on Bringhurst's principles of typography.

Compositor

In letterpress printing, a compositor is the person who arranges type and spacing elements to create a page layout. They work at a composing stick, selecting individual pieces of type and spacing material (furniture, leads, and reglets) to build up lines and pages before locking them into a chase.

Wikipedia: Compositor · Images

Chase

A chase is a rectangular metal frame used in letterpress printing to hold the composed type and spacing material securely in place. Once the compositor has arranged all the elements, they are locked into the chase using quoins (wedges) and keys, creating a stable form ready for printing.

Wikipedia: Chase · Images

Em

An em is a typographic unit equal to the current font size. For example, if your type size is 12pt, then 1em = 12pt. Ems are relative units that scale with the font size, making them ideal for spacing elements like gutters and margins in typography.

Wikipedia: Em · Practical Typography
